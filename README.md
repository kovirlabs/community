# Kovir Labs community

This is where anyone can suggest software that would help mission-driven organizations. It is
also where people ask questions about Kovir Labs projects and share what they've built with them.

**→ [Suggest an idea](https://github.com/kovirlabs/community/discussions/new?category=ideas)** ·
[Browse ideas](https://labs.kovir.org/ideas) · [labs.kovir.org](https://labs.kovir.org)

No GitHub account? Use the [contact form](https://labs.kovir.org/contact?type=idea) or email
info@kovir.org instead.

## How ideas become software

Kovir Labs, the development arm of [Kovir LLC](https://www.kovir.org), builds tools that many
organizations can use, not custom software for one. The best ideas describe a need that others
share.

1. **Suggest.** Anyone can open a discussion in **Ideas**. Describe the problem, who has it, and
   how it's handled today.
2. **Show demand.** Upvote and comment on the ideas that matter to your organization.
3. **Kovir decides.** The kovir.org team reviews new ideas **monthly** and decides which ones
   Kovir Labs takes on. The decision is posted as a comment and a label.
4. **Labs builds and supports.** Accepted ideas become open-source projects maintained by Kovir
   Labs.

Being accepted is a commitment. It is not a delivery date.

## Labels

| Label | Meaning |
|---|---|
| `status: under-review` | New. Waiting for the next team review. |
| `status: accepted` | The kovir.org team agreed that Kovir Labs will take this on. |
| `status: in-progress` | Being built. |
| `status: shipped` | Released. The closing comment links the release or the project page. |
| `status: not-now` | Not taking this on for now, with a short reason. |
| `source: form` | Came in through the website contact form and was posted anonymously, with permission. |
| `source: kovir-client` | Raised by an organization Kovir works with. |

The idea board on [labs.kovir.org/ideas](https://labs.kovir.org/ideas) is built from these labels
and refreshes daily.

## Categories

- **Ideas**: needs and feature requests. Upvotes are on.
- **Q&A**: questions about using a Kovir Labs project.
- **Announcements**: news from Kovir Labs (maintainers only).
- **Show and tell**: share how your organization uses a Kovir Labs tool.

Bugs in a specific project go to that project's own issue tracker.
